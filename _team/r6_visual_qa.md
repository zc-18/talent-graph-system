## 三、Lane G 自查发现并已修复的两处回归

### 回归 A：100vh 处背景硬边、首屏以下大片纯白
- **成因**：`html, body, #root { height: 100% }` 使根元素盒子恰好一屏高，而背景**定位区域**取根元素盒子；叠加 `background-repeat: no-repeat`，超过 100vh 的部分只剩 `background-color`。
- **影响面**：`/`、`/jobs`、`/jobs/:id`、`/talent`、`/dashboard`、`/feedback` 全中。
- **修法**：把柔光洗整体移到 `body::before` 的 `position: fixed; inset: 0; z-index: -1` 独立合成层。
  **不是** `background-attachment: fixed`——那条被设计契约明令禁止（移动端逐帧重绘）。
- **文件**：`frontend/src/index.css`（已随 `9f6a2e1` 提交）

### 回归 B：门户 KPI 四标签对比度 2.61:1
- 原用 `.label` 的 `text-body-3`（`#94A0BF`），白卡上仅 **2.61:1**，而这四个标签正是第 1 项点名「必须可见」的元素。
- 改为 `text-body-2`（`#5A678C`），**5.59:1**，过 WCAG AA。
- **文件**：`frontend/src/pages/Portal.tsx`（已随 `fa69cb6` 提交）

### 新验 2 — 回归 A 复验：背景无硬边、首屏以下非纯白 — **通过**

**CSS 层实测**（`getComputedStyle(document.body, '::before')`）：

```
position: fixed          z-index: -1          inset: 0px 0px 0px 0px
background-attachment: scroll, scroll, scroll, scroll     ← 不是 fixed，契约满足
图层: [radial-gradient, radial-gradient, linear-gradient, url]   ← 四层齐全
html 自身: backgroundImage=none, backgroundColor=rgba(0,0,0,0)
```

最后一行很关键：`html` 没有自己的背景，body 背景才会传播到 canvas、body 自己不再绘制，
`z-index:-1` 的伪元素才不会被埋。这正是 `index.css` 注释里点名的易碎点，**当前成立**。

**像素层实测**（1440×900，取页面右缘 x 1434–1438 的纯背景竖条，逐行采样 900 行）：

| 页面 | scrollHeight | 采样位置 | 视口顶 / 中 / 底 | 逐行最大跳变 | 恰等于 `--surface-page` 的行数 |
|---|---|---|---|---|---|
| `/dashboard` | 1272 | scrollY=0 | (229,224,249) / (237,233,248) / (236,232,248) | **1** | **0 / 900** |
| `/dashboard` | 1272 | scrollY=372（到底） | (229,224,249) / (237,233,248) / (236,232,248) | **1** | **0 / 900** |
| `/jobs` | 3487 | scrollY=0 | (229,224,249) / (237,233,248) / (236,232,248) | **1** | **0 / 900** |
| `/jobs` | 3487 | scrollY=2587（到底） | (229,224,249) / (237,233,248) / (236,232,248) | **1** | **0 / 900** |

三条判定：

1. **没有硬边**：逐行最大跳变 = **1**（0–255 标度）。硬边的特征是几十级的单行突变；此处全程平滑。
2. **不是纯白 / 不是回落色块**：`--surface-page` 是 `rgb(242,245,251)`，回归态下 100vh 以下每一行都会恰好等于它。实测 **0/900 行**命中，实际值是 (236,232,248) 一带的淡紫柔光洗；视口 y=4 与 y=895 之间仍有 **8** 级色差，说明渐变还在画，不是被拍平成单色。
3. **确实是固定合成层**：`scrollY=0` 与滚到底时，**同一视口坐标的最大色差 = 0**。背景完全不随文档滚动 —— 这正是 `position: fixed` 合成层的特征，也是回归态（背景随文档、过 100vh 即消失）不可能出现的结果。

`/jobs` 滚到 2587，已是 100vh 的 **2.9 倍**深度，背景仍完整。

**顺带核了 `/`（门户，匿名）**：scrollHeight 1709，滚到 809 时 100vh 接缝应落在视口 y=91 —— 该处无任何边界。
截图中可见的两条横向分界在视口 y≈205 与 y≈812（对应文档 y≈1014 / 1621），是门户自身分段 section 的底色交界，**不是 100vh 接缝**；右缘 top/bottom 色差 28 也来自这些会滚动的 section 底色，不是背景层。

**证据**：`g2b-dashboard-top.png` / `g2b-dashboard-bottom.png` / `g2b-jobs-top.png` / `g2b-jobs-bottom.png` / `g2b-portal-top.png` / `g2b-portal-bottom.png` / `g2_log2.txt`

- 可选修法（供决策）：把按钮渐变换成 `--brand-accent-deep` 一侧的深色，或给按钮文字加极轻的暗色描边/阴影。
