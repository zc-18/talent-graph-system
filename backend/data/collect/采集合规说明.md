# 数据采集合规说明（台账）

本项目所有招聘数据均以**合法、合规、可溯源**方式获取，用于高校竞赛研究用途。逐源说明如下。

## 合规基线（代码级强制，见 `collect/base.py`）

1. **只采公开信息**：仅访问无需登录即可查看的公开职位列表/详情页；不携带任何登录态，不绕过登录墙，不破解验证码。
2. **robots.txt 检查**：每个 host 请求前检查并缓存 robots.txt，被 Disallow 的路径直接放弃并记录日志。
3. **控频**：单 host 请求间隔 ≥4 秒 + 随机抖动（远低于正常浏览频率），UA 标明研究用途。
4. **零个人信息**：只采集企业发布的岗位商业信息；字段名含 phone/wechat/email/联系人 等直接抛错拦截（`base.py::emit` 的 `_PII_FIELD_BAN`）；JD 正文中的手机号/邮箱/微信号在落盘前正则打码（`mask_pii`）。
5. **全程留痕**：每批次保存 原始数据 jsonl + 每请求一行的 crawl_log.jsonl + manifest.json（批次元数据），本地归档即数据佐证。
6. **不复现反爬签名**：凡是需要复现 JS 生成的签名/令牌、解密自定义字体、或过人机校验才能取到数据的源，一律**不采**（逐源实测结论见下文「实测被阻断/放弃的源」）。

## 新增数据源说明（2026-07-27）

### 新增源 A：飞书招聘 SaaS 企业招聘官网（`*.jobs.feishu.cn`，tier=official，权威度 1.0）

- **是什么**：一批企业把自己的官方招聘官网托管在飞书招聘 SaaS 上，域名形如 `{企业}.jobs.feishu.cn`（个别企业用自有域名，如 EcoFlow 的 `jobs.ecoflow.com`）。这些站点是**企业自己面向公众发布岗位的官方渠道**，因此定 tier=official、权威度 1.0，与腾讯/网易招聘官网同级。
- **租户来源**：`probe_feishu_tenants.py` 共探测 95 个候选 slug，其中公开职位数 > 0 的有 11 家，写入 `data/collect/feishu_tenants.json` 的 `valid` 列表；适配器只读这 11 家（依据 `feishu_tenants.json` 的 `"checked": 95`）。

  | 企业 | 站点 | 官网公开职位数 |
  |---|---|---|
  | 蔚来 NIO | nio.jobs.feishu.cn | 2170 |
  | 小鹏汽车 | xiaopeng.jobs.feishu.cn | 1616 |
  | 得物 App | poizon.jobs.feishu.cn | 547 |
  | EcoFlow 正浩创新 | jobs.ecoflow.com | 178 |
  | 零一万物 | 01ai.jobs.feishu.cn | 56 |
  | 生数科技 | shengshu.jobs.feishu.cn | 56 |
  | 出门问问 Mobvoi | mobvoi.jobs.feishu.cn | 17 |
  | Insta360（影石） | arashivision.jobs.feishu.cn | 15 |

  | 猎户星空 | orionstar.jobs.feishu.cn | 8 |
  | 爱奇艺 | iq.jobs.feishu.cn | 1 |

- **为什么合规**：
  1. **无需登录**：整个采集过程不携带任何登录态、不注册账号、不使用 Cookie 身份。
  2. **csrf token 是公开发放的**：`/api/v1/csrf/token` 面向所有访客（含未登录访客）直接下发 token，属于会话卫生机制，**不是访问控制**，取用它不构成"绕过权限"。
  3. **未复现、未绕过反爬签名**：浏览器请求上会带一个 `_signature` 参数，我们**没有去逆向或复现它**；实测把该参数整个去掉后接口照常返回 200 并给出同样的公开职位数据——这恰恰说明该接口本身对公众开放，我们只是以更朴素的方式访问了同一份公开数据（依据 `data/collect/adapters/feishu_ats.py` 文件头合规注释、`data/collect/probe_ats_report.json` 中各租户 `GET/POST /api/v1/search/job/posts` 的 200 记录）。
  4. **只取岗位商业信息**：标题/职责/要求/城市/发布时间；不碰任何候选人或 HR 信息。
  5. **控频照常**：11 家是 11 个独立 host，`base.fetch` 的单 host ≥4 秒间隔对每家分别生效；适配器采用多租户轮转，只是让不同 host 的等待互相重叠，**没有降低任何一家的请求间隔**。
- **本批采集量**：请求 203 次，采集 **1829** 条，robots 拦截 0、错误 0（依据 `data/raw/2026W31-r2/manifest.json` 与 `feishu_ats.jsonl` 行数）；入库时按新一代信息技术领域过滤（`data/import_raw.py::is_it_domain`），实际入库 **629** 条。

### 新增源 B：国聘网（www.iguopin.com，tier=gov，权威度 1.0）

- **是什么**：中央广播电视总台主办的国家级公共招聘平台，定位与人社部公共招聘网同级，故定 tier=gov、权威度 1.0。
- **接口**：公开职位检索接口 `https://gp-api.iguopin.com/api/jobs/v1/recom-job`（POST），**无需登录、无需 token**；列表返回体的 `contents` 字段即 JD 全文，因此**不需要再逐条打详情接口**，请求量降到最小。
- **robots 依据**：`www.iguopin.com/robots.txt` 返回 200，`User-agent: *` 分组下无有效 Disallow 规则（解析结果为空串），目标路径未被禁止（依据 `data/collect/probe_report.json` 第 29 条）。
- **个人信息处理**：返回体里含 `contact_user` 等联系人字段，适配器**不读取、不落盘**；即便手滑写入，`base.py::emit` 的 PII 字段护栏（`phone|mobile|wechat|weixin|email|contact|联系人|手机`）也会直接抛错拦截（依据 `data/collect/adapters/iguopin.py` 文件头注释与 `base.py` 第 30 行正则）。
- **本批采集量**：请求 78 次，采集 **633** 条，robots 拦截 0、错误 0（依据 `data/raw/2026W31-r2/manifest.json` 与 `iguopin.jsonl` 行数）；领域过滤后入库 **571** 条。

## 探测结论

**2026-07-24（第一轮）**

- 美团 zhaopin.meituan.com：接口要求登录 → **放弃**（不碰登录墙）。
- 字节 jobs.bytedance.com：接口有反爬防护 → 暂不采，如需走浏览器渲染方案再评估。
- 华为/京东：接口路径变更/302 → 暂不采。
- 智谱官网 careers、人社部公共招聘网 job.mohrss.gov.cn：HTML 可解析，列为后续扩展源。

**2026-07-27（第二轮，成规模实测）**

- 覆盖面：`probe_sources.py` 对 **39** 个候选站点（27 个企业官网 + 5 个政府/公共就业平台 + 7 个聚合平台）逐一取 robots.txt 并对入口发 1 次 GET，结果落盘 `probe_report.json`；`probe_ats.py` 另对飞书 ATS 及若干候选接口做了极小量探测，结果落盘 `probe_ats_report.json`；`probe_feishu_tenants.py` 探测 95 个飞书租户 slug，结果落盘 `feishu_tenants.json`。探测阶段**只发极少量请求、不采任何数据**。
- 启用：飞书招聘 SaaS 官网（11 家企业，tier=official）、国聘网（tier=gov）——见「新增数据源说明」。
- 不启用：全部 aggregator 类平台，逐条理由见「实测被阻断/放弃的源」。
- 待观察：中国公共招聘网 `/cjobs/cb21/query`（本轮 502）、国家大学生就业服务平台（入口 403）。
