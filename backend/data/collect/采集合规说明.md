# 数据采集合规说明（台账）

本项目所有招聘数据均以**合法、合规、可溯源**方式获取，用于高校竞赛研究用途。逐源说明如下。

## 合规基线（代码级强制，见 `collect/base.py`）

1. **只采公开信息**：仅访问无需登录即可查看的公开职位列表/详情页；不携带任何登录态，不绕过登录墙，不破解验证码。
2. **robots.txt 检查**：每个 host 请求前检查并缓存 robots.txt，被 Disallow 的路径直接放弃并记录日志。
3. **控频**：单 host 请求间隔 ≥4 秒 + 随机抖动（远低于正常浏览频率），UA 标明研究用途。
4. **零个人信息**：只采集企业发布的岗位商业信息；字段名含 phone/wechat/email/联系人 等直接抛错拦截；JD 正文中的手机号/邮箱/微信号在落盘前正则打码。
5. **全程留痕**：每批次保存 原始数据 jsonl + 每请求一行的 crawl_log.jsonl + manifest.json（批次元数据），本地归档即数据佐证。

## 数据源清单

| 源 | 层级(tier) | 权威度 | 方式 | 合规依据 |
|---|---|---|---|---|
| 腾讯招聘 careers.tencent.com | official | 1.0 | 公开查询接口(GET) | 企业官方招聘官网，面向公众主动发布；无登录墙；robots 未禁止 |
| 网易招聘 hr.163.com | official | 1.0 | 公开查询接口(POST) | 同上 |
| 公开历史数据集（天池/Kaggle 等） | dataset | 0.7 | 官方渠道下载 | 平台以公开数据集形式发布，按其许可证用于研究 |
| 人社部新职业文件/头部机构报告 | authority | 1.0 | 新闻原文快照归档 | 公开政策文件与公开发布的行业报告，用于新兴岗位佐证（`data/authority/`） |
| 主流招聘平台（Boss/智联/猎聘） | aggregator | 0.8 | （如启用）小规模控频 | **单独批次隔离**，可整批剔除；不登录、不采个人信息；风险自评后决定是否纳入 |
| GitHub 公开仓库 north-jewel/data_analysis 之 51job_3.csv（前程无忧 2018-12 采集，5654 条 IT 岗位含 JD 全文） | dataset | 0.7 | GitHub raw 直接下载（无需登录） | 公开仓库托管的历史研究数据；**仓库未声明许可证**，本项目仅作科研评测历史基线（batch `2018hist-r1`，筛选 300 条），保留出处与原始文件佐证（`data/raw/_datasets/51job_3.csv`），不再分发。来源：https://github.com/north-jewel/data_analysis （文件提交于 2018-12-06，commit "前程无忧Python 5000+数据"） |

## 探测结论（2026-07-24）

- 美团 zhaopin.meituan.com：接口要求登录 → **放弃**（不碰登录墙）。
- 字节 jobs.bytedance.com：接口有反爬防护 → 暂不采，如需走浏览器渲染方案再评估。
- 华为/京东：接口路径变更/302 → 暂不采。
- 智谱官网 careers、人社部公共招聘网 job.mohrss.gov.cn：HTML 可解析，列为后续扩展源。
