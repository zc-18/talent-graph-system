## 二、测试数据集（双轨制）

系统采用**双轨数据集**：

- **轨道①　对抗测试夹具 / 合成解析基准**（`docs/测试数据/seed_jds.json`，379 条）：人工可控注入抄袭、能力通胀等对抗样本，配套逐条真值标签，用于**可复现的定量评测**（清洗检出率、JD 解析准确率）。该数据集**不进入生产图谱**，仅作评测基准。
- **轨道②　生产真实语料**（806 条真实 JD）：2018 历史基线（前程无忧公开数据集 300 条，2018-12 采集）+ 2026 现网（腾讯招聘 255 条 + 网易招聘 251 条，官网公开接口合法采集，批次 2026W31-r1）。SimHash 查重检出 25 条重复。线上系统（DB `talent_graph_v2`）的岗位/技能/演化图谱**全部由该真实语料构建**：岗位 29 个（新兴 6 + 既有 23）、技能 2387 项（粗粒度 426 + 细粒度技能点 1961）、证据 3363 条 + 权威佐证 8 条。

### 2.1 对抗基准 JD 数据集（`docs/测试数据/seed_jds.json`）

- **规模**：379 条 JD，覆盖 **31 个**新一代信息技术岗位簇，横跨 **人工智能 / 大数据 / 智能系统 / 物联网 / 云计算与工程** 五大技术栈：
  Java 开发、机器学习、大数据开发、算法、自然语言处理、计算机视觉、大模型应用开发、推荐/搜索算法、知识图谱、自动驾驶系统、服务机器人、数字孪生、嵌入式软件、边缘计算、工业物联网、云原生、MLOps 等。
- **真实性设计**：每条 JD 在职责措辞、技能子集、动词表述、排版模板上充分变化（多模板 + 同义动词），贴近真实"相似但不相同"的招聘文本。
- **对抗样本（用于验证数据清洗）**：
  - **抄袭样本 8 条**：整段复制已有 JD 仅改公司名/来源（验证近似去重；系统另自动检出 3 条模板高度相似的近重复，共 11 条）；
  - **能力通胀样本 17 条**：在正常技能外注入 6 个与岗位明显无关的冷门技术词（区块链、量子计算、FPGA、同态加密等，验证通胀检测）。
- **真值标签**（`ground_truth.json`）：每条 JD 标注真实的必备/加分技能、是否抄袭、是否通胀，用于自动化评测。

### 2.2 简历测试集（`docs/测试数据/test_resumes.json`）

- **规模**：18 份简历，覆盖 10 类目标岗位，匹配度分布从高到低（含部分匹配、较大差距样本）。
- **鲁棒性设计**：刻意使用同义词/缩写（torch、k8s、NLP、ML、数仓…）考验"抽取 + 归一化"能力。
- **真值标签**：每份简历标注真实技能集合。

## 三、测试方法与用例

### 3.1 JD 解析准确率

- **方法**：对 371 条非重复 JD 调用大模型解析，抽取必备/加分技能并归一化，与真值标签比对。
- **指标**：精确率 P、召回率 R、F1、重要度分类正确率。
- **结果**（`data/eval_jd_result.json`，n=371）：

```
精确率 Precision : 0.9859
召回率 Recall    : 0.9798
F1               : 0.9825
重要度分类正确率  : 0.9775
```

### 3.2 简历提取准确率

- **方法**：对 18 份简历解析抽取技能，与真值比对（软技能不计精确率惩罚）。
- **结果**（`eval_resume_result.json`）：

```
精确率 Precision : 0.937
召回率 Recall    : 1.000
F1               : 0.965
```

### 3.3 人岗匹配准确率

- **方法**：对每份简历与其目标岗位图谱，逐"必备技能"判定"具备/缺失"，与真值（候选人真实技能 ∩ 岗位必备技能）比对。
- **结果**（`eval_match_result.json`）：

```
分类准确率 : 1.000
匹配 F1    : 1.000
```

### 3.4 数据清洗有效性

| 项目 | 植入 | 检出 | 准确 |
|------|------|------|------|
| 抄袭/重复（对抗基准） | 8 | 8（+3 自动检出近重复） | 100% |
| 能力通胀（对抗基准） | 17 | 17 | 100% |
| 真实语料查重（806 条生产语料） | — | SimHash 检出 25 条重复 | 与人工抽检一致 |

### 3.5 单元测试与覆盖率

- **框架**：pytest + pytest-cov，**72 个用例全部通过**，覆盖清洗、归一化、反幻觉聚合、置信度公式、匹配、演化、分级画像、JD/简历/新岗位定义抽取后处理、API 端点等。
- **覆盖率：63%（≥60% 达标）**。

```
TOTAL  1843 stmts  674 miss  63%
其中核心服务：taxonomy 96% / matching 87% / resume 57%（重解析分支依赖外部文件）
```

### 3.6 既有岗位能力动态演化验证（核心功能②）

- **方法**：以 2018 历史基线（前程无忧公开数据集）为 v1，以 2026 现网真实语料（腾讯/网易招聘）为 v2，跨 **2018→2026 八年跨度**做真实 diff，自动标注「新增 / 删除 / 修改」并溯源。
- **规模**：**14 个岗位完成真实 v1→v2 演化，共 100 条演化记录**，每条含变更原因（reason）与数据来源（data_source：真实平台名 + JD 数）。
- **在线可见**：`/evolution` 页面历史记录 + 岗位详情「演化历史」标签（新旧对照）。
- **示例**（Java 开发工程师 v1→v2 节选）：

| 变更 | 能力项 | 更新说明 | 数据源 |
|------|--------|----------|--------|
| 🟢 新增 | 大语言模型 | Java 后端开始要求对接大模型能力中台 / AI 网关 | 5 独立来源 + 联网佐证 |
| 🟢 新增 | 检索增强生成（RAG）| 知识库问答 / 智能客服场景驱动后端集成 | 4 独立来源 + 联网佐证 |
| 🟢 新增 | 向量数据库 | 伴随 RAG 落地成为后端新增数据组件 | 4 独立来源 + 联网佐证 |
| 🟢 新增 | 云原生 | 云原生架构（Service Mesh/Serverless）持续渗透后端 | 5 独立来源 + 联网佐证 |
| 🟡 修改 | Kubernetes | 容器化部署由「加分」升级为「必备」 | 9 独立来源 |
| 🟡 修改 | 微服务 | 需求热度上升（权重 0.74 → 0.95）| 9 独立来源 |
| 🔴 删除 | JSP | 前后端分离 + Spring Boot 普及后过时淘汰 | 最新 JD 窗口连续未出现 |

> 验证「既有岗位能力动态更新」闭环：变更项可量化、可溯源、可人工优化，岗位定义随市场数据持续进化。

### 3.7 置信度校准（说明）

- **统一公式**：C = 0.35·支持率 + 0.20·来源多样性(平台数/3 封顶) + 0.15·时效性(半衰期 180 天) + 0.20·来源权威度(官网/政府 1.0、公开数据集 0.7、网络 0.6) + 0.10·外部验证；五个因子逐项落库（`job_skill.factors`），前端点击置信度徽章可见分解。
- **校准过程**：初版来源多样性上限为 5 平台，在真实语料（仅 3 个采集平台）上系统性压低得分；据此将 DIVERSITY_CAP 由 5 调整为 3，并将岗位整体置信度改为**粗粒度 active 能力项的权重加权平均**。用真实语料校准一次后**冻结参数**，不做逐岗调参。
- **结果**：全库岗位置信度均值 **0.535** —— 这是真实数据下的诚实数字（合成数据可轻易刷高），答辩文档中有专门说明。

### 3.8 分级画像评估

- **规模**：**22 个岗位**建有 初/中/高 三档分级画像（`job_level_skill`），构档规则：**每档 ≥3 条 JD 且岗位 ≥2 档**才产出，避免小样本档位噪声。
- **可验证性**：中级→高级晋升 diff 可在线查询（如 AI智能体开发工程师：晋升到高级需新增掌握 云原生 等 8 条能力项）。

## 四、复现方式

```bash
# 1) 对抗基准数据集（评测轨道）
uv run python data/generate_dataset.py
uv run python data/generate_resumes.py
uv run python data/run_pipeline.py --reset --use-cache   # 基于合成基准评测清洗/解析

# 2) 生产真实语料（生产轨道，目标库 talent_graph_v2）
uv run python data/migrate_202609.py --db talent_graph_v2
uv run python -X utf8 data/collect/run_collect.py --platforms tencent,netease --batch 2026W31-r1
uv run python -X utf8 data/import_raw.py --batch 2026W31-r1 --tier official
uv run python data/run_pipeline.py --from-db             # 真实 JD 构建图谱
uv run python -X utf8 data/run_evolution_batch.py        # 2018→2026 真实 v1→v2 演化
uv run python -X utf8 data/seed_new_jobs.py              # 6 个证据背书的新兴岗位
uv run python -X utf8 data/build_levels.py               # 初/中/高分级画像

# 3) 准确率评测（三项核心指标）
uv run python data/evaluate.py all

# 4) 单元测试 + 覆盖率
uv run pytest --cov=app --cov-report=term-missing
```
